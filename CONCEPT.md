# Run — the living terminal

A landing page for a CLI or coding agent where the terminal is the hero.

A command types itself. Little robots spawn, open files, run tests, and report back. The terminal is the product demo: you can see what the tool actually does, one task at a time.

## First build

1. Static terminal card with a prompt, a command, and output.
2. Typing animation and a task queue.
3. Canvas robot sprites that move between terminal rows.
4. A real command run in a sandbox or a scripted demo.
5. Sound, reduced motion, and a 60-second demo.
